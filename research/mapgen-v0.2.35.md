# Original numbered terrain generation

New City now offers **New numbered city** alongside the retained nine extracted cartridge maps and Free Megacity. Players can preview maps000–999, name the city and choose Easy/Medium/Hard. Generated cities start in1900 with the original difficulty funds20000/10000/5000. Information shows the map number; city saves, automatic session restore and the player-requested restart preserve its provenance. The actual generated geography is stored in the ordinary map array.

## Source translation

- `CODE_03D834` seeds the global map/menu RNG from the adjacent ones/tens/hundreds bytes and performs its original warmup loop.16-bit reads overlap these bytes; the high half of the hundreds read is the prior ones-cache byte. Its initialFF value changes a carry and therefore the warmup count. The first preview and a subsequently changed preview can produce different terrain for the same number. The API retains `previousOnes`, and the UI retains the prior preview cache. Repeating an unchanged preview does not consume RNG.
- `CODE_00824F` adds the two seed words, stores the first result, then adds the old first word with the prior carry to form the returned second word. This remains separate from the seven-word simulation RNG. Generated cities inherit the final map/menu words instead of resetting them.
- `CODE_01F1F1..01F923` supplies the island/river decision, island clearing/coastal erosion, two broad river walks, narrow tributary, lake brushes, shoreline classification, forest walks and two in-place forest-smoothing passes. Bounds,16-bit coordinate wrapping, brush visit order and descending smoothing order are preserved. The tributary updates the base direction while retaining the prior current-direction state, as the source does.
- `CODE_01F877` multiplies the low random byte by maximum+1 and uses the high byte of that product. Its two-draw minimum helper,9x9/6x6 brushes, shoreline and forest tables are copied from the matching ROM. The native JavaScript implementation has a defensive65536-step river guard; every supported map tested terminates normally.
- `CODE_028B34`/`DATA_02948E` provide the terrain preview's color indices. The retained MapSelect tilemap has a15x13 rectangle of195 palette7 entries (columns6–20, rows43–55 in the unpacked buffer); MainMenu palette7 supplies RGB. This avoids aliasing full-size city sprites down to tiny tiles. The modern dialog is not a claim of original full-screen/HDMA composition parity.

`tools/extract-mapgen-tables.mjs` regenerates embedded tables from the preserved matching USA ROM and retained palette. No ROM, CPU emulator or reference runner is needed by the playable browser generator.
